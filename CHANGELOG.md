# CabinBuddy Changelog

Version format: Major.Minor.Patch
- Major: big changes to how CabinBuddy works for everyone
- Minor: new features or noticeable improvements
- Patch: small fixes and cleanups

The newest version at the top is the one shown at the bottom of the side menu.

## [2.4.6] - 2026-11-18
### Changed
- Removed Sync Data and the Admin Tools shortcut from Current & Past Stays
- Moved Adjust Billing for Reservation into Financial Dashboard; retired the separate Financial Admin Tools page and sidebar link, with old links redirected to the dashboard
- Existing payments, stays, and automatic refresh behavior are unchanged

## [2.4.5] - 2026-11-18
### Changed
- Removed the bulk "Link Orphaned Payments" action from Current & Past Stays; existing payments and stays are unchanged

## [2.4.4] - 2026-11-18
### Changed
- Removed the "Sync Payments" tool from Financial Admin Tools and Stay History, so payment records are no longer created in bulk from check-in logs

## [2.4.3] - 2026-11-18
### Changed
- Financial Admin Tools: removed outdated debugging tools (Fix Empty Occupancy Charges, Link Orphaned Payments, Cleanup Duplicate Payments)

## [2.4.2] - 2026-11-18
### Changed
- The version window now opens with the three newest releases and a "Show older updates" button for the rest

## [2.4.1] - 2026-11-18
### Added
- Clickable version number at the bottom of the side menu opens this changelog
### Changed
- Removed the minimum-nights line from the Calendar status dropdown
- Season Readiness no longer flags seasons whose selection is already finished
### Fixed
- "Yes, I've Paid" after Venmo now records the payment in one step, with a clear reminder to return to CabinBuddy
- Completed maintenance to-dos now appear in the Maintenance Log

## [2.4.0] - 2026-11-17
### Baseline
- Starting point for the changelog. Includes Current & Past Stays, Payment History, post-rotation free selection hold, season setup reminders, print layouts for Stay History and Family Group Overview, and the Avenger Initiative.
